Independent verification

Recompute a lottery position yourself

You should not have to take our word for the draw. Enter any application number and this page shows the exact input string and the SHA-256 of it that fixed that application's place in the queue, along with the command to reproduce it on your own machine.

Lottery token hash

Check it on your own machine

printf '%s' "seed:FH-2026-000123" | sha256sum

Applications are sorted by this token, smallest first. Doing that for every application number reproduces the whole draw order, without needing this website, our database or our source code.

Why it is built this way

A seeded random number generator would be reproducible in theory, but only for someone running the same programming language and library version we did. That is not verification, it is a second act of trust. A hash of two published strings can be checked with a one-line command on any computer, which is the whole point.

The published result also carries a hash over the entire ordered decision list (hash), so a downloaded copy of the list can be checked for tampering without access to our systems.
