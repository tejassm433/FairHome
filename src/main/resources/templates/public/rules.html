How the draw is ordered

The lottery order is fixed by SEEDED_LOTTERY: 

position key = SHA-256( "seed" + ":" + application number )
applications are sorted by that key, ascending

notes

There is no random number generator, so there is nothing to trust about our machine or our software version. Two strings go in, a hash comes out, and any SHA-256 tool gives the same answer.

Reserved quotas

Each of these is carved out of every income category, in the order listed. A qualifying applicant gets first claim on the reserved seats and then competes for the open seats too. "Existing area resident" is a reserved quota in its own right, not a tiebreaker.

A quota can only refer to one of the tests above. They are fixed in the software and listed here in full, so re-weighting a quota is a published edit but redefining what a quota means is not something an operator can do quietly.
