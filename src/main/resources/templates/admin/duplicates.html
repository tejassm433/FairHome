How to read these

A same national ID flag with everything else matching is almost always one person submitting twice because they were unsure the first one went through. A name and date of birth flag where the ID differs by one digit is usually a typing error, either theirs or ours, and needs the physical forms compared. Two genuinely different people sharing a birthday and a common name do happen, which is exactly why this queue exists instead of an automatic delete.
