What gets checked before publishing

  • Category quota percentages must total exactly 100.
  • Income bands must be contiguous, with no gaps and no overlaps, and the top band must be open-ended, so no declared income can fall outside every category.
  • Reserved quota percentages must not exceed 100% of a category.
  • Every reserved quota must name a test that exists in the software.
  • A lottery seed is mandatory. Without it the draw would not be reproducible.
  • The policy for unclaimed reserved seats and unfilled category seats must be stated explicitly, not left to be decided on the day.

A rule book that fails any of these is refused outright. Refusing to run is always better than producing a result nobody can defend.
